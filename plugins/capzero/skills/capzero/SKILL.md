---
name: capzero
description: Reference for working in CapZero when the user asks to use their installed apps.
---

CapZero provides your organization's apps, records and actions. The user's request determines the work. `app_guide` offers optional reference for an installed app; `operation_describe` finds permitted actions and their input schemas. `operation_call` calls an action discovered by name. Results include available `next` actions and errors include a `fix`.
